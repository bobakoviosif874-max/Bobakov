## Как загрузить новые работы в этот репозиторий

1. В верхней части страницы репозитория нажмите кнопку **Add file** -> **Upload files**.
2. Перетащите файлы выполненных лабораторных (например, ваши PDF, картинки интеллект-карт или отчеты).
3. Нажмите зеленую кнопку **Commit changes** внизу страницы.
4. После загрузки обновите ссылки в таблице выше, чтобы они вели на конкретные файлы.
