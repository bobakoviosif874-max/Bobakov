## Структура материалов в репозитории

Каждая лабораторная работа изолирована в своей директории:
* `/lab1/` — скриншоты досок планирования, чек-листы и ссылки на внешние документы.
* `/lab2/` — экспортированные ментальные карты предметной области (в формате картинок или PDF).
* `/lab3/` — исходные файлы разметки документов и финальные скомпилированные PDF-отчеты.
* `/lab5/` — презентация beamer (не менее 5 слайдов, содержащая таблицы и графические элементы).
* `/lab7/` — файлы данных и книга с построенными аналитическими дашбордами Tableau.
